# Support: ScrollTamilBible Welcome to the official support page for ScrollTamilBible. Common Troubleshooting & FAQs: - How do I change the menu language? Go to Settings -> App language -> Select English / Tamil. - How do I increase the font size? Go to Settings -> Text size -> Select Small / Medium / Large. - How do I change the Appearance? Go to Settings -> Appearance -> Select System / Light / Dark. - Can I read offline? Yes, ScrollTamilBible functions fully without an active internet connection.
